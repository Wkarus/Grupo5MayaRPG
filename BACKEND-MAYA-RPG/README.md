# BACKEND-MAYA-RPG (NestJS)

Backend NestJS do projeto (módulo alternativo/experimental).

## Instalação

```bash
cd BACKEND-MAYA-RPG
npm install
```

## Rodar

```bash
npm run start:dev
```

## Build

```bash
npm run build
```

## Testes

```bash
npm run test
```

> Observação: o fluxo principal atual do projeto está no backend Express (`backend/`), usado pelo app e pelo admin-web.
