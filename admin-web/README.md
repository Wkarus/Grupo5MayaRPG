# Admin Web (MayaRpg)

Painel administrativo web (React + Vite).

## Funcionalidades atuais

- login admin
- dashboard com indicadores
- agenda (bloquear/desbloquear horários)
- comentários (moderação)
- posts
- exercícios (cadastro/lista)
- pacientes (CRUD + busca/filtro + status)
- prontuário por paciente

## Rodar local (dev)

```bash
cd admin-web
npm install
npm run dev
```

Exemplo:

```bash

```
